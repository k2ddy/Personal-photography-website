# 留光 · 摄影作品集

一版可直接浏览和继续迭代的个人摄影作品站。当前版本是无构建依赖的静态站点，部署目录为 `dist/`。

## 已完成

- 全屏沉浸式照片轮播与柔和交叉淡化
- 液态玻璃顶部导航、当前栏目液滴指示
- 左下角个人头像与简介卡片
- 不规则作品拼贴、桌面端 Dock 式悬浮反馈
- 全屏灯箱、键盘方向键、Esc、移动端滑动切换
- 浏览器本地批量上传，自动生成轻量展示图与缩略图，随后替换演示图库并接管首页轮播
- 姓名、身份、简介、所在地、邮箱与头像的站内编辑
- 桌面与移动端响应式布局、减少动态效果支持、键盘焦点与图片替代文字

## 本地预览

```bash
python3 -m http.server 4173 --directory dist
```

打开 `http://127.0.0.1:4173`。

## 数据说明

作品文件通过 IndexedDB 保存在访问者当前浏览器中；个人资料文字保存在 localStorage 中。当前版本适合单机整理与视觉确认，还不支持跨设备同步。后续可接入对象存储与元数据数据库，并保留现有页面和作品数据结构。

演示作品均为本项目生成的原创占位素材。网页使用的是 `dist/assets/demo/*.webp` 优化版本，原始 PNG 保存在 `source-assets/demo/`。

## 主要文件

- `dist/index.html`：页面结构与可访问性语义
- `dist/styles.css`：视觉系统、液态玻璃、响应式与动效
- `dist/app.js`：轮播、图库、灯箱、上传、本机存储与个人资料
- `.openai/hosting.json`：Sites 部署配置
