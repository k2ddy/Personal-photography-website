# 摄影作品集

一版可直接浏览和继续迭代的个人摄影作品站。当前版本是无构建依赖的静态站点，部署目录为 `dist/`。

## 已完成

- 满屏沉浸式照片轮播与柔和交叉淡化，支持上一张 / 下一张
- 液态玻璃顶部导航、当前栏目液滴指示
- 左下角个人头像与简介卡片
- 独立作品集页面、更紧凑的不规则作品拼贴、桌面端 Dock 式悬浮反馈
- 独立深色“关于我”页面，保留完整个人叙事与合作信息
- 按类型、年份、拍摄设备与横竖画幅组合筛选
- 左右铺满的作品网格，末行保持同类照片尺寸并左对齐；全屏大图保留完整构图，空余区域以同图高斯模糊填充，底部显示拍摄信息
- 全屏灯箱、键盘方向键、Esc、移动端滑动切换
- 沉浸式深蓝地图页面：蓝色省界与填充，按上传照片的 GPS 归属中国省级行政区，照片越多蓝色越深，点击省份查看照片
- 浏览器本地批量上传，自动生成轻量展示图与缩略图，随后替换演示图库并接管首页轮播
- JPEG EXIF 读取：拍摄时间、GPS、相机、镜头、焦距、光圈、快门与 ISO
- 姓名、身份、简介、所在地、邮箱与头像的站内编辑
- 桌面与移动端响应式布局、减少动态效果支持、键盘焦点与图片替代文字

## 本地预览

```bash
python3 -m http.server 4173 --directory dist
```

打开 `http://127.0.0.1:4173`。

## 数据说明

作品文件通过 IndexedDB 保存在访问者当前浏览器中；个人资料文字保存在 localStorage 中。当前版本适合单机整理与视觉确认，还不支持跨设备同步。后续可接入对象存储与元数据数据库，并保留现有页面和作品数据结构。

EXIF 只在当前浏览器读取，不会发送到服务器。JPEG 通常可以读取较完整的信息；PNG、WebP、AVIF 或经过社交平台压缩的照片可能没有可用 EXIF，此时页面会显示“未记录”。GPS 坐标属于敏感信息，正式公开站点前建议增加逐张隐藏或模糊位置的选项。

演示作品均为本项目生成的原创占位素材。网页使用的是 `dist/assets/demo/*.webp` 优化版本，原始 PNG 保存在 `source-assets/demo/`。

地图只统计实际上传的照片，演示作品不参与足迹统计。省界 GeoJSON 随站点本地保存，GPS 在浏览器内进行多边形匹配，不调用第三方逆地理编码服务。无 GPS 和未匹配照片单独计数；边界附近可能存在数据精度或坐标系误差。地图数据来自 [China-GeoData](https://github.com/Supeset/China-GeoData)，保留原始 GeoJSON 与 MIT 许可证 `dist/assets/china-map-LICENSE.txt`。请通过本地 HTTP 服务器浏览，直接打开 HTML 文件可能无法加载地图。

## 主要文件

- `dist/index.html`：满屏沉浸式主页与个人简介卡片
- `dist/portfolio.html`：独立作品集、组合筛选与照片详情
- `dist/about.html`：独立个人介绍与联系页面
- `dist/map.html`：省级照片分布地图与区域作品列表
- `dist/geography.js`：经纬度归属、多边形判断、地图投影与颜色分级
- `dist/styles.css`：视觉系统、液态玻璃、响应式与动效
- `dist/app.js`：轮播、图库、筛选、灯箱、上传、本机存储与个人资料
- `dist/metadata.js`：JPEG EXIF 解析与拍摄参数格式化
- `.openai/hosting.json`：Sites 部署配置
