# 摄影作品集

一版可直接浏览和继续迭代的多用户摄影作品站。当前版本使用无第三方依赖的 Node.js 服务，`dist/` 为前端页面，`server/` 负责注册登录、权限与各用户的独立图库。

## 已完成

- 满屏沉浸式照片轮播与柔和交叉淡化，支持上一张 / 下一张
- 液态玻璃顶部导航、当前栏目液滴指示
- 左下角个人头像与简介卡片
- 独立作品集页面、更紧凑的不规则作品拼贴、桌面端 Dock 式悬浮反馈
- 独立深色“关于我”页面，保留完整个人叙事与合作信息
- 按类型、年份、拍摄设备与横竖画幅组合筛选
- 作品网格两侧与筛选栏细线对齐，末行保持同类照片尺寸并左对齐；全屏大图保留完整构图，空余区域以同图高斯模糊填充，底部显示拍摄信息
- 全屏灯箱、键盘方向键、Esc、移动端滑动切换
- 沉浸式深蓝地图页面：蓝色省界与填充，按上传照片的 GPS 归属中国省级行政区，照片越多蓝色越深，点击省份查看照片
- 用户注册、登录后拥有独立图库与公开个人主页；原站主的首页与作品保持独立
- 本人登录后批量上传，自动生成展示图与缩略图；作品保存在服务端，任何访客都可浏览该用户的公开作品
- 上传、移除作品、更新头像与资料均由服务端校验所属账号；查看他人主页时不显示编辑入口
- JPEG EXIF 读取：拍摄时间、GPS、相机、镜头、焦距、光圈、快门与 ISO
- 姓名、身份、简介、所在地、邮箱与头像的站内编辑
- 桌面与移动端响应式布局、减少动态效果支持、键盘焦点与图片替代文字

## 本地预览

需要 Node.js 22 或更高版本，无需安装依赖。在项目目录执行：

```bash
npm start
```

普通用户注册不依赖管理员配置。若要管理站点原来的主主页，在终端运行 `npm run admin:password`，设置至少 12 个字符的管理员密码，输入不回显。

- 访客页面：`http://127.0.0.1:4173`
- 注册 / 登录：`http://127.0.0.1:4173/account.html`，也可从右上角账号图标或页脚进入
- 注册填写昵称、用户名和密码；用户名为 3–24 位字母、数字或下划线，字母开头，不区分大小写；密码 12–256 个字符
- 登录后点“管理作品”，或在自己的页面使用右上角“添加作品”；账号页也提供编辑资料和主页分享链接
- 用户主页：`http://127.0.0.1:4173/u/用户名`，访客无需登录；首页、作品集、地图和关于页均只展示该用户的内容
- 站点原主页仍是 `/`；站主管理入口为 `/admin.html`，也可在账号页以用户名 `admin` 登录
- 工作台 / 账号页可以退出登录；会话最长 12 小时，服务重启或退出后失效
- 重置站主管理员密码：`npm run admin:password`；只撤销管理员会话，不影响普通用户
- 本轮尚未实现普通用户的密码找回、邮箱验证或账号注销；不要把这版直接开放到公网

不再使用 Python 静态服务器；用户系统和图库需要 Node 后端。权限与持久化测试：`npm test`。

## 数据说明

作品、缩略图和资料保存在服务器的 `.data/` 目录。原站主的 `library.json` 和 `admin.json` 保持原位置；新增 `accounts.json` 存储普通用户账号及加盐密码哈希，`users/<用户 ID>.json` 存储各自图库与资料，`media/` 保存展示图片。账号文件和图库源文件不作为静态文件开放，公开 API 只返回主页资料及作品，不包含密码哈希。`.data/` 已加入 Git 忽略，备份时需要单独保存整个目录。

会话使用 HttpOnly / SameSite Cookie，HTTPS 下增加 Secure。写入接口从登录会话确定图库所有者，不接受客户端指定其他所有者；删除他人照片返回不存在。前端写入附带预期账号 ID，避免同一浏览器另一个标签页切换账号后误写入新账号。注册和登录有基础频率限制；每个图库最多 500 张。

此前存在 IndexedDB 的作品不会自动公开或删除。请使用原来的浏览器、原来的 `http://127.0.0.1:4173` 地址以站主管理员登录，进入工作台点击“导入当前浏览器的旧作品”。此入口仅站主可见，避免同一设备上的其他账号误导入旧作品。导入后立即对访客可见，原本地数据保留。旧个人资料与头像可在管理员工作台重新保存。

移除作品后，公开列表与图片地址不再提供该作品；磁盘原文件仍保留用于恢复。未上传时，访客看到空图库，不显示演示作品。

所有用户主页及上传作品默认公开，不是私人网盘。注册页和上传工作台均有公开提示。EXIF 在上传者浏览器中读取，提取的拍摄参数和 GPS 随展示图保存到服务端并用于公开展示。原始文件不直接上传。JPEG 通常可以读取较完整的信息；PNG、WebP、AVIF 或经过社交平台压缩的照片可能没有可用 EXIF，此时页面会显示“未记录”。GPS 坐标属于敏感信息，正式公开站点前建议增加逐张隐藏或模糊位置的选项。

保留的演示素材均为本项目生成的原创占位素材，不计入公开图库。网页使用的是 `dist/assets/demo/*.webp` 优化版本，原始 PNG 保存在 `source-assets/demo/`。

地图只统计实际上传的照片，演示作品不参与足迹统计。省界 GeoJSON 随站点本地保存，GPS 在浏览器内进行多边形匹配，不调用第三方逆地理编码服务。无 GPS 和未匹配照片单独计数；边界附近可能存在数据精度或坐标系误差。地图数据来自 [China-GeoData](https://github.com/Supeset/China-GeoData)，保留原始 GeoJSON 与 MIT 许可证 `dist/assets/china-map-LICENSE.txt`。请通过 Node 服务浏览，直接打开 HTML 文件无法使用共享图库和管理员功能。

## 主要文件

- `dist/index.html`：满屏沉浸式主页与个人简介卡片
- `dist/portfolio.html`：独立作品集、组合筛选与照片详情
- `dist/about.html`：独立个人介绍与联系页面
- `dist/map.html`：省级照片分布地图与区域作品列表
- `dist/geography.js`：经纬度归属、多边形判断、地图投影与颜色分级
- `dist/styles.css`：视觉系统、液态玻璃、响应式与动效
- `dist/app.js`：用户主页上下文、轮播、图库、筛选、灯箱、本人工作台与旧本机图库导入
- `dist/account.html` / `dist/account.js` / `dist/account.css`：注册、登录、账号工作台与公开主页分享
- `dist/admin.html` / `dist/admin.js`：管理员登录与首次使用提示
- `dist/api.js`：图库 API 与预期账号校验
- `server/index.mjs`：用户注册、独立图库、公开媒体访问、会话和服务端授权
- `server/password.mjs`：本机设置/重置管理员密码
- `server/server.test.mjs`：跨账号隔离、公开访问、会话撤销、注册校验与持久化等测试
- `dist/metadata.js`：JPEG EXIF 解析与拍摄参数格式化
- `.openai/hosting.json`：之前静态版本的 Sites 配置，本轮未改动、未发布

## 后续部署

本轮完成本地可运行版本，没有更新线上网站。正式上线必须同时部署后端和持久存储，不能仅上传 `dist/` 到静态托管。

当前 Node 服务默认只监听 `127.0.0.1`。部署到 Node 主机时，通过 `HOST`、`PORT`、`SITE_ORIGIN`（精确 HTTPS 来源）和 `PORTFOLIO_DATA_DIR`（持久目录）配置，使用 HTTPS 反向代理。保持固定来源以校验 Host 和写请求 Origin；不要将数据目录设在 `dist/` 下。

当前 JSON 存储面向本地、小规模单进程运行，不支持多进程同时写入。公开注册正式上线前，还需接入可靠数据库 / 对象存储、账号找回、滥用防护、存储配额和隐私管理。

若继续使用此前的 Sites 托管，需要另行迁移为其服务端模板，接入 Sites 身份认证及 D1/R2；本地密码会话不直接搬到 Sites。
